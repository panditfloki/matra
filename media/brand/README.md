# Approved Logo-18

`matra-logo-18.png` is the user's Adobe Express artwork, supplied as
`dydxFIT Logo-18.png`. It is retained unchanged as the branding master.

Regenerate application assets with `powershell -File scripts/build-brand-icons.ps1`.
This creates the multi-resolution Windows ICO, the tray PNG and Settings PNG.
The coral meter, white central mark and transparency are preserved.

The artwork is separate from CodeNotch's upstream code and license notices.

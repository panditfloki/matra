# Mātrā native upgrades · 31 October 2026

These additions extend the existing macOS dashboard, notch and settings.

| Addition | Where to use it |
| --- | --- |
| Refresh on attention and completed work | Opening the usage menu or hovering a notch card refreshes readings. Settings → General can request the source directly. Provider rate floors and backoff still apply. |
| Menu attention and controls | Appearance settings: working animation, waiting dot, completion feedback, click action and compact reading width. Right/control click retains the menu. |
| Quota ordering | Manual, remaining allowance and expiring allowance order. Stale/signed-out accounts do not outrank usable quota. |
| Grok Bot and Higgsfield | Accounts settings. Grok Bot reads its selected account's local cache; old/reset readings are stale. Higgsfield uses its own CLI/credential and preserves unknown allowances. |
| Account/project activity and INR estimates | Dashboard → Project activity; Settings → Costs. Claude/Codex logs are indexed by turn, account, project, session and day. Day/week/month and account/project filters reconcile to the same totals. |
| Custom protocols and OpenCode activity | Custom Endpoints supports OpenAI-compatible, Anthropic and Gemini discovery/usage requests. Enter an exact OpenCode provider ID and optionally a model. Install/remove the metadata-only bridge with the explicit Settings buttons, then restart OpenCode. |
| Local runtimes | oMLX settings and the llama.cpp custom-endpoint preset. llama.cpp metrics require `--metrics`. Monitoring does not generate inference requests. |

Costs distinguish subscription allocation, estimated API-key usage and
API-equivalent usage. Missing prices or FX are unavailable; partial totals say
“At least”. A real zero remains zero. Model versions need an exact normalized
price entry. Amounts are INR estimates, not invoices or GST calculations.
Historical estimates use the currently configured plan price; there is no price
history. Local transcripts cannot account for work performed on another device.
The existing offline Spend dashboard remains separate from the new native Activity
index and can have different coverage.

The OpenCode bridge writes state, identifiers and generic labels. It omits
prompts, answers, tool arguments and prompt-derived titles. Preview and installed
identities have separate bridge files and storage. Removing the bridge restores
a displaced non-bridge file when available.
